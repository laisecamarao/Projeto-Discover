# ✨ Discover — Projeto Web

Projeto desenvolvido como **atividade avaliativa da disciplina de Desenvolvimento Web**, ministrada pela maravilhosa professora Suzana Lustosa.

A atividade foi baseada no curso **Discover**, da [Rocketseat](https://www.rocketseat.com.br/), que apresenta conceitos fundamentais do desenvolvimento web.

## Sobre o projeto

O projeto consiste em uma página de perfil personalizada, com links para sites e redes sociais. A página possui dois temas visuais: modo escuro (*dark mode*) e modo claro (*light mode*), que podem ser alternados por meio de um botão.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização, layout responsivo, cores, imagens de fundo e animações.
- **JavaScript:** alternância entre os temas e atualização do avatar.
- **Ionicons:** ícones das redes sociais.
- **Google Fonts:** fonte Inter.

## Funcionalidades

- Exibição de avatar e nome de perfil.
- Links para portfólio, redes sociais e outros conteúdos.
- Alternância entre os modos claro e escuro.
- Alteração do avatar conforme o tema selecionado.
- Estilização adaptada para diferentes tamanhos de tela.

## Objetivo

Praticar os fundamentos de HTML, CSS e JavaScript, aplicando conceitos de estruturação, estilização, responsividade e interatividade em uma página web.
